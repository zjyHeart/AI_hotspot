## 验收结果与后续验证

用户已确认功能正常运行。以下项目说明实际使用步骤与仍需独立确认的验证项，不将 SMTP 接受等同于实际收件，也不将有限采集描述为全量覆盖。

1. X、历史兼容服务 和 SMTP 配置已读取并真实测试。当前模型 deepseek-v4-pro，输出模式 json_object；请检查此前的 [Signal Desk] 邮件连接测试 是否实际收到。不要在聊天中发送密钥。
2. 根据令牌分组确认模型 ID 与输出能力。在“连接与设置”测试 历史兼容服务 接口、X 和邮件；检查实际收件箱。官方推荐 历史私有接口（不再作为公开版配置），历史私有接口 也可作为候选地址，须验证它确实提供所需 API。
3. 启用自选关键词 / 领域频道，执行真实扫描；确认 AI 事件有正确原文引用，未核实内容没有被冒充为确定事实。
4. 当符合条件的新内容出现，检查站内未读通知、邮件接受状态与实际收件箱；重复扫描不产生同一版本的重复提醒。
5. 验收页面风格、手机布局、频道编辑、扫描记录及证据可追溯性。默认采集频率 30 分钟，可按频道调整。

当前正式数据的 Web http://127.0.0.1:3000 和 worker 保持运行，原有两个监控仍暂停。http://127.0.0.1:3001 为独立临时数据库的生产验收页面和独立 worker，用于查看本轮真实分析结果，测试数据没有写入正式数据库。应用 Agent Skill 按用户要求在 Web 真实联调通过且用户验收后再开发。
