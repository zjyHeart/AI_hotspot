# 分阶段信息分析 V2：实施与验收记录

日期：2026-10-05（Asia/Shanghai）。用户已确认按 [方案](analysis-pipeline-v2-plan.md) 开发。本轮 Web 实现、回归和真实小样本联调完成，等待用户验收；Agent Skill 尚未开发，代码尚未 Git 提交。

## 已实现

- 采集与分析解耦：采集保存原始材料、推进游标并入队；worker 独立消费初筛和深度任务。分析失败不重新搜索。
- X 保留低互动、回复、短文本和未知作者候选，作为标签交给 AI；空内容、用户屏蔽账号、纯转发做确定性排除。保留跨渠道发现 URL、作者、来源和完全相同正文的合并路径。
- Google/Bing 查询轮转及分页分别使用 start/first；保持 30 分钟基础采集、240 分钟网页刷新、30 次/天及 900 次/月搜索预算。每轮每引擎检索次数、候选入队上限、活跃窗口、展示价值阈值均可配置。RSS、HN、GitHub 继续复用现有采集，不擅自新增订阅。
- 逐候选初筛保存相关性、新信息、价值、主体、动作、版本、日期、明确理由。输入漏项、重复 ID 或无效日期拒绝成功提交；旧文保留为背景，未知日期可分析。
- 初筛入选后按事件簇读取新旧支持及反对材料；长文最多保存 30,000 字符，从全文选取相关段落，注明未读部分。少量 X 父帖查询、原文提取、事件补查均有独立上限和缓存，不承诺完整线程或全网覆盖。
- 深度核验采用服务器生成的短原文片段 ID。AI 选择 evidence.quoteId 与 claims.quoteIds；服务器还原对应的连续原文并校验 ID、文章归属、实际读取范围、重复引用和逐项材料集合。每篇材料仍只有一个总证据项，每项说法另附对应短引用。不会截短、拼接或接受模型伪造的引用来绕过校验。
- 持久化队列含租约、响应隔离、有限重试/退避、预算暂停、阶段和版本缓存；调整窗口或分析配置重新排队，最近 5 次失效结论保存在候选审计字段中。不同主体、版本、日期不会仅凭相似标题合并。历史低价值事件保留记录但退出默认列表。
- 页面增加 Aceternity Bento 处理统计、候选结论、阶段任务/耗时、调用/token 预算、手动分析与重试。事件有价值/影响、逐项核验、对应原文、证据缺口及反馈。反馈作为调优记录，不自动改变事实可信度。
- 新增数据库增量迁移 0003；升级前以 VACUUM INTO 生成一致备份，备份失败则不继续升级。没有清库或目录删除。

## 默认设置与运行方式

自动分析默认关闭，手动“分析已有材料”可以请求分析，后台 worker 必须在线。正式启用前在“连接与设置”确认预算并打开自动分析，再运行 `rtk proxy npm run worker`。运行中的频道才自动消费；暂停频道可以显式手动分析。

默认：AI 60 次/天、200,000 tokens/天，初筛最多使用 80% 给深度阶段留额度；X 父帖查询 10 次/天，初筛批次 3，候选入队上限 200，活跃窗口 72 小时，价值阈值 60，每引擎每轮检索次数 1。已有模型、地址、输出模式配置继续读取。失败调用计入次数；未知 usage 不按零统计，保留请求预算估计。预算是本机保护机制，供应商可能另有计费规则。

已配置 deepseek-v4-pro 的分阶段请求默认使用稳定输出：`thinking: {type: "disabled"}` 与 json_object。这一字段只作用于精确匹配的已验证模型及 screen/deep 阶段；其他模型、旧对照和连接测试保持各自协议。默认思考模式仍可选择，但本轮曾发生截断和超时。

## 同主题真实材料对照

主题 AI coding agent。X 1 次请求获得 20 条，Google 1 次请求获得 9 条，Bing 1 次请求获得 10 条；保存 39 篇去重材料。X 达到 1 页上限，状态 partial，游标保留。没有重复搜索，也没有事件补查请求。

从 X、Google、Bing 各选 2 条，共 6 条真实材料进行 V1/V2 对照。它是覆盖不同材料类型的小样本，不是随机代表性评测。

| 材料 | 旧单阶段分析 | V2 最终结论 |
| --- | --- | --- |
| Codegen 编程代理比较，原文日期为 2026-03 | 输出为一条事件 | 超过 72 小时窗口，保留背景，不展示 |
| LinkedIn 代码审查文章 | 未生成事件 | 信息不足；原文 HTTP 451，保留摘要与失败状态 |
| Morph 九月榜单 | 未生成事件 | 信息不足；原文 HTTP 429，保留摘要与失败状态 |
| YouTube Freebuff 宣传片段 | 输出免费开源代理事件 | 信息不足，价值 40；没有可读正文，保留线索，不展示 |
| X 仅短链接 | 未生成事件 | 信息不足；发现文章链接但没有获取可用正文 |
| X AgentSmith 工作流介绍，5 点赞 | 输出待核实事件 | 初筛入选，深度核验后展示；逐项短原文通过本地校验，仍待核实 |

旧方案成功调用生成 3 条事件；新方案最终展示 1 条。首次 V2 初筛对 Freebuff 给出低价值（50），最终同材料复测判信息不足（40）；这说明模型结论会波动，审计和严格来源边界仍然必要。

AgentSmith 的帖子支持“该帖子作出了这些功能和许可证声明”，尚无官方仓库或独立实测证明工具实际状态。深度核验指出官方链接、实际发布状态、集成细节、演示和效果等缺口；没有将“有材料支持”冒充绝对真实，也没有触发通知。模型建议事件日期可能取自帖文日期，详情明确保留实际发布日期待核实的缺口。

正文情况：1 篇完整网页、1 条有实质内容的 X 原帖、3 篇正文获取失败的网页、1 条未获得文章正文的 X 链接。没有把 native、摘要或搜索命中统一算成完整正文读取。

本轮可观察到旧文和正文不足宣传退出展示、低互动具体工作流保留。但只有 6 条材料，无法可靠估计总体准确率、召回率、误收率、重复率或质量提升百分比，也不能据此证明所有消息真假。

## 调用、费用与故障记录

- 本轮调试和新旧对照合计 21 次 PackyAPI 请求，已知 usage 62,313 tokens；5 次未返回可用 usage，仍保守预留 72,223 tokens。未知用量不是实际账单，不将失败请求视为免费。
- 合计含最初临时库未继承已保存 json_object 配置的 4 次 HTTP 400、1 次超时，以及后来有已知 usage 的截断/Schema 引用失败。配置问题仅修复临时验证库，未自动更改正式输出模式。
- 模型曾重复引用文章、复制超过 250 字符的原文；先拒绝，再修改引用协议，最终用片段 ID 完成真实验证。服务器没有放宽来源校验。
- 最后同材料复测使用 2 次初筛 + 1 次深度，共 6,492 已知 tokens，展示 1 个待核实事件；该数仅是这个小样本的有效事件分析成本，不含采集、旧对照、调试和正文请求，不可外推为普遍单事件价格。
- SerpAPI 2 次请求，事件补查 0；X 搜索 1 次、父帖查询 0。通知 0、邮件 0。
- 页面预算暂停与重试验证另用真实待处理队列执行；网络函数被禁止，实测外部请求为 0，AI 调用数仍为 21。反馈保存 1 条，可信状态仍未改变。
