# X 账号监控与信息筛选验收

日期：2026-10-05（Asia/Shanghai）。用户已批准开发，本记录用于 Web 验收；本轮未提交 Git，未开发 Agent Skill。

## 完成的功能

- AI 编程与 Agent 专题：OpenAI、AnthropicAI、cursor_ai、cline、opencode、LangChain、simonw、steipete 八个精选账号；支持增删、暂停、身份依据和频道开关。账号查询与关键词查询分别保存窗口及游标，不要求精选账号的帖子必须命中关键词。
- 普通账号默认标准互动门槛：点赞 ≥10 或转发 ≥3 或回复 ≥5，支持宽松、严格和自定义。精选与已确认官方账号豁免互动门槛，仍需 AI 核验。蓝 V 不豁免过滤，不自动增加可信证据。
- 新帖默认观察 120 分钟，到期按预算批量更新互动数据后再判断。更新失败、记录缺失或额度不足继续观察，不使用旧互动数据最终淘汰。纯转发、无实质内容回复、空内容和屏蔽账号保留原始记录及过滤原因。
- 全部 X 请求共用日/月额度，默认 144/4320 次、每频道每轮最多 3 次；账号、关键词、互动复查、父帖及连接测试失败也计数。两条采集路径轮换，未完成窗口继续分页。共享请求间隔默认 6 秒，可配置，属于本机保守策略。
- AI 深度分析单独输出重要性及原因；紧急等级需要具体安全、故障或破坏性变更证据。旧事件显示未评估，重新分析后更新。热度、相关性、重要性和可信度分别处理。
- 信息流支持搜索、时间、来源、频道、重要性、可信状态、最低相关性、账号范围及互动门槛；同维度 OR、跨维度 AND。服务器筛选整个事件库后分页，浏览器保留选择，支持重置和移除单个筛选。
- 排列支持推荐、重要性、相关性、X 社交热度、最新发布和最新发现。推荐按重要性→相关性→首次发现；X 热度为点赞+转发×3+回复×2。限时可靠发布时间筛选排除未知日期，发布排序把未知日期置后。

既有频道保留宽松互动策略，编辑时应用专题可启用标准策略及精选监控。设置和元数据使用现有 JSON 存储，保留历史 SQL 默认值；本轮 X 功能不引入额外破坏性迁移。此前分析流水线 V2 的未提交改动一并保留。
